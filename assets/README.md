# Assets de Magyc

Esta carpeta recibe unicamente assets que el juego consume en runtime.

El pipeline y las convenciones estan en `docs/ASSET_PIPELINE.md`.

Estructura objetivo:

```text
assets/game/characters/mage/
assets/game/enemies/slime/
assets/game/environment/ground/
assets/game/environment/trees/
assets/game/environment/doors/
assets/game/objectives/crystal/
assets/game/effects/fireball/
```

Los renders de referencia, prompts y material intermedio no deben mezclarse con los assets finales de runtime.
